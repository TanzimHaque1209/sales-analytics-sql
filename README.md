# Sales Analytics using SQL

## Project Overview

This project is a beginner-friendly SQL sales analytics workbook focused on creating a simple relational database, inserting sales and product data, and writing analytical queries to extract business insights.

The project demonstrates core SQL concepts used in data analyst roles, including filtering, sorting, aggregation, grouping, joins, and category-wise sales analysis.

---

## Dataset Description

The workbook uses two main tables:

### 1. `sales`

Contains order-level sales data, including:

* Order ID
* Customer name
* Region
* Product
* Quantity
* Sales amount

### 2. `products`

Contains product information, including:

* Product ID
* Product name
* Category
